# IA générative en assurance

Support de formation en 4 modules, publié sur GitHub Pages :
<https://ia-generative-assurance.github.io/>

1. Je découvre : le chatbot vu de l'intérieur
2. Je comprends : du mot-clé au Transformer
3. J'applique : mes usages, avec les bons outils
4. Je prototype : mes outils, sans construire seul

Ce dépôt contient uniquement le site HTML généré (pages, feuilles de style, images).
Les sources de construction (fragments `content/`, `build.py`, export PDF) restent
dans le dépôt de travail et ne sont pas publiées ici.
