La question Humain

Une question de gestionnaire, concrète, dont la réponse est quelque part dans les huit pages.

La boucle d'agent, tour par tour IA Règle

À chaque tour, le modèle décide d'un appel d'outil. L'outil, lui, est du code : il cherche vraiment dans les pages ci-contre, et ce qu'il rend est ce que vous voyez.

Cliquez « Tour suivant ».

La réponse IA

Rédigée à partir des pages lues, chaque affirmation appuyée d'une citation entre guillemets. Les citations se modifient : changez un mot, et regardez la vérification en dessous.

Le contrat, page par page Règle

Ce que l'agent peut lire. En ambre, les pages qu'il a ouvertes.

Essayez l'outil vous-même Règle

Le même rechercher que celui de l'agent. Essayez « coupure de courant », puis « coupure ».

    Vérification des citations Règle

    Chaque citation est recherchée telle quelle dans le texte du contrat. Pas de modèle ici : une recherche exacte, et c'est ce qui rend la réponse auditable.

      Contrat fictif écrit pour la démonstration, aucun assureur réel, aucun appel à un modèle depuis cette page. Les décisions de l'agent sont rejouées telles qu'un modèle les prend sur ce genre de question ; les outils, eux, tournent pour de vrai sur les pages. La thèse est dans la dernière carte : une réponse d'agent ne vaut que si chaque citation se retrouve mot pour mot dans le document. Sans cette vérification, faite hors du modèle, l'audit ne tient pas.
